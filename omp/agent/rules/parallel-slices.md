# 按独立性决定是否委派

多步任务先识别依赖关系。能各自完成和验收的工作才算独立切片；同一目标的连续步骤不是多个切片。

1. **单线工作自己做。** 小任务、只有一个独立目标或有顺序依赖的步骤由主代理完成，不为启动子代理制造工作。
2. **独立工作一次并行。** 有 ≥2 个互不依赖的切片时，必须用一次 `task` 的 `tasks[]` 批量下发；每项明确目标、非目标、验收方式。如需写入，先划定互不重叠的写面。
3. **整合有 owner。** 并发写者指定一个收口人，汇总结果后统一验证；共享文件先拆清写面，不能安全拆分时按真实依赖处理。
